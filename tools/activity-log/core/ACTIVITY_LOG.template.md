# Workspace Activity Log

**Scope:** Workspace-wide continuity across agent sessions.
**Status:** Active. Use `CONTEXT.md` for the current handoff snapshot and project-specific activity logs for detailed repo history when needed.

This log is the broad workspace journal. Hooks append a lightweight trail of edited files and activity checkpoints. Agents add narrative milestones after substantive work. The Stop hook refreshes the neighboring `CONTEXT.md` as an overwritten summary of the current state.

Do not add secrets, PII, transcripts, or duplicate deliverable content.
